# SPIC asmeninės pagalbos demo

Talpinimas: įkelkite index.html ir .nojekyll į GitHub saugyklos pagrindinį katalogą. Settings → Pages → Deploy from a branch → main → /(root).

## Vizitų planavimas
Asistentas planuoja tik gavėją, dieną ir atvykimo valandą. Numatoma trukmė ar pabaiga neregistruojama. Planą gali perkelti arba atšaukti pats asistentas. Koordinatorius ir administratorius mato komandos grafiką. Faktinė trukmė skaičiuojama paspaudus Pradėti ir Užbaigti.

## Koregavimo prašymas
Asistentas atidaro užbaigtą įrašą ir prašo leidimo koreguoti. Nurodo priežastį. Koordinatorius arba administratorius patvirtina arba atmeta. Tik patvirtintas prašymas atveria konkretaus įrašo konkrečią versiją. Pataisymas išsaugo seną versiją, sunaudoja leidimą, panaikina naujos versijos parašą ir grąžina įrašą patikrai. Koordinatorius gali ir pats grąžinti įrašą taisyti.

## Dokumentai
Mokėjimo pranešimas pagal pateiktą šabloną. Paslaugų suteikimo aktas už pasirinktą laikotarpį automatiškai užpildo datas, pradžią, pabaigą, valandas ir bendrą sumą. Kokybės vertinimas, pastabos ir mėnesio dokumentų parašai pildomi popieriuje.

## Ribos
Išgalvoti duomenys. Vieno HTML failo vietinė demonstracija. Nėra tikros autentifikacijos, serverio kontrolės, kopijų ar apsaugoto audito. GPS, laiškai ir sinchronizavimas imituojami. Skaičiavimo formulę ir iš kliento šablono perkeltą tekstą prieš realų naudojimą patvirtina klientas. Nenaudoti tikrų asmens duomenų.

Excel eksportas – CSV; PDF – naršyklės spausdinimas. HTML kopija išsaugo dabartinę demonstracijos būseną.
